# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the safety of our users and their data seriously. If you discover a security issue or vulnerability in OpenFileRescue:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the repository maintainers.
3. Include detailed reproduction steps, system details, and potential impact.

We will review reports promptly and publish patches alongside release notes.
